## Inherited from M0

### Re-verify decorator contract under real session ✅ resolved

The M0 `@require_role` decorator read `user_id` from `kwargs["user_id"]`. At M1 the
contract is replaced: both `@require_role` and `@audit_action` read from `args[0]`
(the Reflex State instance) via `args[0].current_user_id`. A new `@public_handler`
decorator marks intentionally unauthenticated handlers.

- `durgam/auth/decorators.py` — rewritten with State-aware wrappers
- `tests/unit/test_auth.py` — updated to new contract (mock State as `args[0]`)
- Decision: M0 kwargs pattern is removed by design; not backward-compatible.
- Documented in `docs/modules/auth.md` → Decorator Contract section.
