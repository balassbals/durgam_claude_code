# M8 — Leave Rules

**RFP reference:** Informal requirements ("Leave approval is very special and should follow leave rules doc precisely"); `docs/leave_rules_sssihl.pdf` is the institutional source.
**Branch:** `m8-leave-rules`
**Predecessor:** M7 (Approval Requests) — gate passed 2026-06-07

---

## Scope (to be refined during orient)

Implement faculty + student leave request and approval workflow per `docs/leave_rules_sssihl.pdf`. Leverage the M7 approval engine as the underlying state machine; M8 adds the LeaveRequest domain (with rules), a LEAVE_APPROVAL process configured via the existing ApprovalProcess admin, leave-specific UI (request form, balance view, history), and the leave-rules logic (entitlements, accruals, cancellations, withdrawals, extensions).

## Carries forward from M7

- Approval engine (`ApprovalRequest`, `ApprovalStep`, scope-chain routing, channel-based stages, skip-self logic, post-approval callback registry, channel-membership-based nav gating).
- NRF auto-creation pattern is the model for "on terminal approve, create domain record" — leave approvals follow the same pattern, but for `LeaveRequest`.
- Active TDs that may touch M8: TD-029 (more_info_requested state — relevant for "send back for more info" during leave review), TD-032 (notification dispatch worker — leave approvals will accumulate more pending rows until this lands).

## Inherited from M0

Property-based tests with hypothesis for the rules engine. Leave rules are a natural fit (entitlement calculations, accrual periods, cancellation rules). Consider implementing during M8 orient as the property-test foundation, or defer to a dedicated milestone.

3. Faculty vs student vs staff: same workflow or separate processes?
4. Half-day, hourly leaves, compensatory off — in v1 or deferred?
5. Leave balance view: how does the requestor see their balance pre-submit?
6. Warden-side permission-taking flow (per informal reqs) — same process or separate?
7. Approver chain for leave: usually HOD → Dean / HOD → Registrar / etc. — configurable per leave type or universal?
